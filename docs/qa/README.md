# Q&A Sessions

This folder stores structured question-answer sessions used to refine product, architecture, and implementation decisions before or during development.

Use this folder when:

- The user answers product questions.
- Architecture tradeoffs are discussed and resolved.
- Scope boundaries are clarified.
- Important technical assumptions are confirmed.

## Naming Format

```text
YYYY-MM-DD-session-001.md
```

## Recommended Sections

- Topic
- Questions
- Answers
- Decisions taken
- Docs updated
- Impact on implementation
