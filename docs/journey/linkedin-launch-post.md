# LinkedIn Launch Post

I’m starting work on a new project called Udbhavi.

The idea came from a very personal problem.

I was updating my resume in Overleaf, and doing it manually in LaTeX was honestly tiring and repetitive. I tried giving the content to LLMs and other chat-based tools, but the output usually missed what actually mattered: fitting the template properly, keeping it clean, making it one-page, and preserving good formatting.

Then I changed the way I approached it.

Instead of treating it like generic text rewriting, I started treating the resume like a structured formatting problem. I refined my prompts, added stricter instructions around template fit, page limits, and formatting quality, and used agent-style workflows to generate better LaTeX. After that, I could paste the output into Overleaf and get a polished PDF that actually looked right.

That experience made me think:

Why should this still be this manual for everyone else?

So I’m now building Udbhavi, an AI-powered resume workspace focused on helping people create, improve, target, and export high-quality resumes without fighting formatting every time.

The direction right now is:

- structured resume data as the source of truth
- LLM for rewriting, optimization, and targeting
- deterministic rendering for polished output
- support for clean PDF and editable resume workflows

I’m still early in the build, but this is one of those ideas that feels worth pursuing because it came from a real pain point I faced myself.

Would love to share the journey as I build it.
